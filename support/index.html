COORDSMITH / SUPPORT

Keep the toolkit sharp.

Found a wrong result, a confusing interaction, or a map handoff that failed? A clear, reproducible report helps.

Report an issue

The configured support channel is GitHub issues. Reports in the website support tracker are public. Do not include private coordinates or personal information. For test-build access, contact the person who supplied your build.

Open GitHub issues ↗

A useful report includes

  • The app version, operating system, and device model.
  • The steps you took and what you expected to happen.
  • A safe sample input and the observed result, including units and coordinate order.
  • A screenshot if it explains the issue. Remove sensitive locations and personal information first.

Testing the release candidate

There is no public app-store download yet. Authorized testers can install the Android APK supplied with a release or build it from the repository. The configured minimums are iOS 15 and Android 7.0 (API 24). iOS development testing requires Xcode and a simulator, or device provisioning. Build artifacts are test builds, not store-signed releases.

Common questions

Does CoordSmith work offline?

Local parsing, coordinate conversion, calculations, and saved data work offline. Map tiles and launching online services need a network.

Why does it ask me to choose coordinate order?

Some pairs are valid as both latitude/longitude and longitude/latitude. CoordSmith presents both interpretations so the decision stays with you.

Do I need location permission?

Only to use your current location. Pasting coordinates, calculations, and saved points work without it. You can change permission in system settings.

Can I use results for surveying or navigation?

Use independent verification for critical work. The app is a utility, not certified surveying or safety-critical navigation equipment. See the Terms of Use.
